# SarmayeYar — سرمایه‌یار

نسخه 1.0.0 — GitHub-ready

این پروژه برای Build ابری با GitHub Actions آماده شده است.

## امکانات
- مدیریت دارایی‌ها
- واحد پایه تومان
- ثبت تعداد/واحد و ارزش هر دارایی
- داشبورد و ترکیب سبد
- تحلیل ساده سبد
- سناریوساز انتقال سرمایه
- تاریخچه و نمودار رشد
- پشتیبان‌گیری JSON
- قیمت آنلاین تتر و طلای ۱۸ عیار
- نگهداری آخرین قیمت ذخیره‌شده هنگام قطع اینترنت
- بدون قفل

## Build
فایل `.github/workflows/android.yml` به‌صورت خودکار APK تستی را در GitHub Actions می‌سازد.

راهنمای کامل در `GITHUB_BUILD_GUIDE.md` قرار دارد.

## نکته قیمت آنلاین
PriceService در یک فایل جدا قرار گرفته تا در صورت تغییر منبع قیمت، فقط همان بخش اصلاح شود.

این برنامه برای مدیریت شخصی سرمایه است و توصیه سرمایه‌گذاری ارائه نمی‌کند.
