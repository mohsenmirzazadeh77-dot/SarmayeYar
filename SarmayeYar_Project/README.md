# SarmayeYar — سرمایه‌یار

نسخه 1.0.0

## امکانات
- مدیریت دارایی‌ها
- واحد پایه تومان
- ثبت تعداد/واحد و ارزش هر دارایی
- داشبورد و ترکیب سبد
- تحلیل ساده سبد
- سناریوساز انتقال سرمایه
- تاریخچه و نمودار رشد
- پشتیبان‌گیری JSON
- قیمت آنلاین تتر از API عمومی نوبیتکس
- قیمت آنلاین طلای ۱۸ عیار از صفحه عمومی TGJU
- نگهداری آخرین قیمت ذخیره‌شده هنگام قطع اینترنت
- بدون قفل

## ساخت APK
1. پروژه را در Android Studio باز کنید.
2. Gradle Sync را اجرا کنید.
3. از منوی Build گزینه Generate Signed Bundle / APK و سپس APK را انتخاب کنید.
4. خروجی Release را بسازید.

## نکته قیمت آنلاین
قیمت تتر از API عمومی نوبیتکس دریافت می‌شود. قیمت طلای ۱۸ عیار از صفحه عمومی TGJU خوانده می‌شود. چون ساختار سرویس‌های عمومی ممکن است تغییر کند، PriceService در یک فایل جدا قرار گرفته تا در صورت تغییر منبع، فقط همان فایل اصلاح شود.

این برنامه برای مدیریت شخصی سرمایه است و توصیه سرمایه‌گذاری ارائه نمی‌کند.
